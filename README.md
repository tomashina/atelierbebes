# Libermedia New

Laravel 12 osnova za novu Libermedia trgovinu, kopirana iz projekta herrera-new.

Lokalno: http://libermedia-new.test

Projekt koristi vlastiti .env, APP_KEY i lokalnu SQLite bazu. Izvorni OpenCart i Herrera baza nisu povezani.

Migracija Libermedia sadržaja i prilagodba dizajna tek slijede. Naslijeđene Herrera naredbe i integracije zahtijevaju prilagodbu prije korištenja.
